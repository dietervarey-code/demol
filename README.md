# De Mol Hongarije

Singleplayer browsergame geïnspireerd op De Mol.

De speler neemt als kandidaat deel aan een seizoen in Hongarije, speelt opdrachten, praat met kandidaten, houdt een Molboekje bij en probeert De Mol te ontmaskeren.

## Techniek

- Vite
- JavaScript
- Canvas
- Frontend-only in eerste fase
- Later uitbreidbaar met Render/backend
